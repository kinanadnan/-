# لعبة سباق سيارات جماعية على المتصفح

هذا المشروع يقدم نموذجًا أوليًا بسيطًا للعبة سباق سيارات جماعية تعمل عبر المتصفح باستخدام **Express** و **Socket.IO**.

## طريقة التشغيل محليًا

1. تأكد من تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
2. نزّل الاعتمادات:
   ```bash
   npm install
   ```
3. شغّل الخادم:
   ```bash
   npm start
   ```
4. افتح المتصفح على العنوان `http://localhost:3000` ثم شارك نفس العنوان مع أصدقائك على نفس الشبكة أو انشره على خادم سحابي لتجربة اللعبة متعددة اللاعبين.

## النشر للعامة

لجعل اللعبة متاحة على جميع الأجهزة عبر الإنترنت يمكنك استخدام خدمات الاستضافة التي تدعم Node.js مثل:

- [Render](https://render.com/)
- [Railway](https://railway.app/)
- [Fly.io](https://fly.io/)
- خوادم VPS أو أي مزود سحابي يدعم تشغيل تطبيقات Node.js

بعد نشر الخادم، شارك عنوان URL الناتج مع اللاعبين الآخرين.

## خصائص اللعبة

- دعم فوري للّعب الجماعي باستخدام Socket.IO.
- لوحة تحكم تعمل باللمس للهواتف والأجهزة اللوحية.
- تصميم متجاوب مع السمات الداكنة والفاتحة.

> **تنبيه**: هذه نسخة تجريبية تعليمية لعرض كيفية بناء لعبة جماعية على المتصفح. يمكنك تطويرها أكثر بإضافة نظام تصادمات، لافتات لفة، مؤثرات صوتية والمزيد.
